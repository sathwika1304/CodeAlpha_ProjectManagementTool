# TaskFlow – Project Management Tool

### CodeAlpha Full Stack Development Internship | Task 3

TaskFlow is a web-based project management application developed using Django. It helps users organize projects, manage tasks, collaborate with team members, and track project progress through a simple dashboard.

## Features

- **User Authentication:** User registration, login, and logout.
- **Project Management:** Create and view projects.
- **Team Collaboration:** Add team members to projects.
- **Task Management:** Create tasks and assign them to users.
- **Task Tracking:** Update task status and monitor progress.
- **Priority Management:** Set task priorities to Low, Medium, or High.
- **Due Dates:** Set deadlines for tasks.
- **Comments:** Add comments to task discussions.
- **Dashboard:** View project and task statistics.

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite
- Git and GitHub
