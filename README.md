# TaskFlow - Project Management Tool

**CodeAlpha Full Stack Development Internship — Task 3**

TaskFlow is a Django-based project management application that helps users organize projects, manage tasks, assign team members, and track progress.

## Features
- User registration, login, and logout
- Create and view projects
- Add project team members
- Create tasks and assign users
- Set task status, priority, and due date
- View task details
- Add comments to tasks
- Dashboard showing project and task counts

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Run Locally
1. Clone this repository.
2. Open the project directory.
3. Create and activate a virtual environment.
4. Install Django:
   `pip install django`
5. Apply migrations:
   `python manage.py migrate`
6. Start the development server:
   `python manage.py runserver`
7. Open `http://127.0.0.1:8000/` in your browser.
